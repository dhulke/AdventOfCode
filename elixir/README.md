# Advent of Code

**Solutions to the Advent of Code challenges in Elixir**

## Installation

Install Elixir following the official documentation: https://elixir-lang.org/install.html

## Testing

Run the following commands to test the puzzle solutions:

```sh
git clone git@github.com:dhulke/AdventOfCode.git
cd AdventOfCode/elixir
mix test
```
